This is a program built using C++ and Raylib to simulate the famous Conway's Game Of Life developed on Windows 11.
The main purpose of this project was to get comfortable with Raylib and even though I cannot prove this, I have not used AI in any instance in this project's development!
To be clear, I'm not against AI in coding but since this project was meant to be learning experience using AI would just make no sense.

Instructions to use:
clone the repository in any folder you wish. Using make command (or mingw32-make on MSYS2), build the game! 
You can increase the speed of the simulation by going into the terminal, writing the execution command and alongside, typing the required speed (set at 5 by default).
